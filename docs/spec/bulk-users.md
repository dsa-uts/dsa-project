# ユーザー一括作成の表操作

Admin の User Accounts → 一括作成で使用する。編集列は userid、username、role、password。列記号や選択範囲のアドレスは表示しない。

- クリックでセル選択、ドラッグ・Shift＋クリック・Shift＋矢印で矩形を選択する。選択の起点セルをアクティブセルとし、矢印で移動、Enter・F2・ダブルクリックで文字編集に入る。文字キーからも入力できる。日本語入力は編集モードで行える。
- 文字編集中の矢印・Delete・単一セルの貼り付けは通常のテキスト操作。Enter・Tab・Escape・フォーカス移動で編集を終える。Escape でも入力済みの変更は保持する。
- セル選択中の Delete / Backspace は範囲内の値を消す。行自体は削除しない。
- セルを右クリックすると「前に行を挿入」「後ろに行を挿入」「選択した行を削除」を表示する。選択範囲内なら選択を維持し、範囲外なら右クリックしたセルを選択する。挿入は選択範囲の先頭行の前・末尾行の後に空行を1行追加する。削除は選択した列に関わらず範囲内の行全体を対象とし、作成済み行を含む場合は無効にする。
- 貼り付けは選択範囲の左上が起点。貼り付けデータの大きさだけを更新し、選択範囲に合わせた繰り返し・拡大縮小はしない。3行目の username に3行×2列を貼り付けると、3〜5行目の username・role だけを更新する。
- データ末尾を超えた貼り付けは行を追加する。最終列（password）を超える貼り付け、作成済み行を含む貼り付け・範囲削除は操作全体を拒否する。
- クリップボードはタブ区切り。空セルは空文字で上書きする。末尾の改行1つを行終端として除き、途中の空行・末尾の空列は保持する。引用符で囲んだタブ・改行、二重引用符による引用符のエスケープを扱う。カンマは文字として保持し、幅の短い行は空セルで補う。不正な引用符はエラーにする。
- 「元に戻す」「やり直す」はセル編集1回、貼り付け1回、範囲削除1回、行追加・挿入・削除1回、ファイル読み込み1回が単位。最大100操作を画面内だけで保持する。文字編集中はブラウザの文字編集履歴を使う。セル選択中は ⌘ / Ctrl＋Z、⌘ / Ctrl＋Shift＋Z、Ctrl＋Y でも操作できる。
- Apply の入力検証開始時に履歴を消去する。作成済み状態や生成済みパスワードを過去の編集履歴で戻さない。処理中は表・ファイル読み込み・履歴操作を無効化する。
- 全列が空の行は作成対象・件数・CSV 出力・離脱確認の対象から除く。一部だけ入力した行は検証対象。空行だけなら Apply は無効。表示用に最低10行とデータ末尾の入力行を用意する。
- CSV / Excel 読み込みは既存データの末尾に追加する。必須ヘッダー・先頭シート・入力検証・作成済み行の保護・失敗行の再試行・作成結果 CSV は既存の作成処理に従う。貼り付け・手入力の空パスワードは Apply の入力検証時に生成する。
